# Jangus 2.0

An orchestrator that starts specialist agents to handle day-to-day work (file/backup upkeep, shop monitoring, inbox triage) without intervention, under a deterministic kernel that is the only thing allowed to act.

Status: Phase 0. Design only, no code. Plan and status: `python3 tools/taskmaster/tasks.py status`. Start with [CLAUDE.md](CLAUDE.md), [MEMORY.md](MEMORY.md), [docs/PRD.md](docs/PRD.md), [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/MVP.md](docs/MVP.md), [docs/PHASES.md](docs/PHASES.md) and [docs/BUILD_PLAN.md](docs/BUILD_PLAN.md).
