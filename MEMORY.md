## Decisions (settled)
1. First jobs: shop/order monitoring, inbox triage with drafts, file/backup maintenance.
2. Deterministic kernel is the only actor; agents propose.
3. Tiers T1/T2/T3; owner can promote specific actions T3 to T2 (owner-signed, logged, reversible).
4. Models: **Claude Haiku through the direct Anthropic API is the default cheap model** for routine specialist work; Claude API for orchestration/hard judgment; monthly spend cap; no silent fallback. Local Ollama stays in the code as an **optional provider, off by default** (needs a loopback `[model]` endpoint plus `ollama_enabled`). *Amended 2026-11-04 (ADR-002); was "hybrid: local Ollama for routine" — the owner's PC runs local models too slowly.* Known trade-off: routine work now sends shop and (later) email content to Anthropic.
5. PC first with Windows Task Scheduler (`jangus tick`); VPS later.
6. Agents run fresh per job.
7. Orchestrator drafts specs; inert until owner approves.
8. Approvals via CLI first; phone notifications later; bound to payload hash and expiry.
9. Secrets in Windows Credential Manager; per-agent scoping.
10. Orchestrator delegates via directives (Taskmaster-style task lists); kernel owns task status.
11. Cost discipline: orchestrator is escalation-only with a daily cap; completion/reports/standing jobs are kernel-only; kernel-run tasks use zero tokens; specialists on Claude Haiku (direct API; optional local model only where the owner enabled one), Sonnet low effort when needed; cost metered per role. Since 2026-11-04 the cheap rung is paid, so zero-token-first matters more: kernel-run tasks, recipes, watchers and the cache come before any call.
12. Attempt policy: kernel-counted failures; repeat detection; hard per-task limits; ladder 2 + 1 step-up then stop/alert; only the kernel climbs.
13. Placement: cheapest first (**kernel-run, Haiku, Sonnet low, orchestrator**); a local model on the PC or VPS is an **optional rung the owner may enable below Haiku**, off by default; specs declare `host`; GitHub Actions to be evaluated later (state/ledger durability, secrets). *Amended 2026-11-04 (ADR-002); was "kernel-run, local PC, VPS local model, Haiku, Sonnet low, orchestrator".*
14. Token economy (docs/TOKEN_ECONOMY.md, docs/RECIPES.md): metering per call, price table, pre-call check, alerts 50/80/100%, result cache, recipes from repeated verified solves (owner-approved), watchers, monthly reconciliation, dedicated API key with provider spend limit.
15. Gate: file/backup agent must run 7 days unattended with zero manual fixes before shop or inbox agents.
